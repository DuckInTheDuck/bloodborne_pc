# Bloodborne PC — форк DuckInTheDuck

[English](README.md) · **Русский**

Форк [Supermedo/bloodborne_pc](https://github.com/Supermedo/bloodborne_pc) с доработками для Windows,
на основе [bbport от deadinside28](https://github.com/deadinside28/bloodborne_pc).
Оригинальный x86-64-код игры выполняется нативно. Системные службы PS4 предоставляет
рантайм совместимости, графику переводит в Vulkan рендерер на основе
[shadPS4](https://github.com/shadps4-emu/shadPS4).

**Файлы игры и сохранения не включены.** Нужен собственный расшифрованный дамп Bloodborne:
**CUSA03173, версия 1.09**. Проект не связан с Sony и FromSoftware.

## Возможности

- Ультравайд, включая 2560×1080, с исправленными пропорциями камеры в геймплее.
- Нативная камера мышью для версии 1.09, без ограничения скорости эмулируемым стиком.
- Переназначение клавиатуры, кнопок и колеса мыши без перезапуска игры.
- Общая чувствительность, отдельные оси X/Y, инверсия и учёт пропорций.
- Стрелки для меню; WASD остаётся для перемещения персонажа.
- Упрощённый лаунчер с настройками игры, экрана, графики и управления; расширенные опции вынесены отдельно.
- TAA в родном разрешении, FSR 3.1/4, настройки эффектов и частоты кадров.
- Переносимая сборка с необходимыми DLL, папкой для игры и определением разрешения рабочего стола при первой настройке.
- Сохранение настроек, журнал запуска и исправления переключения окон, плавности кадров и подготовки игры.

Новые upstream-возможности DLSS и сетевой игры в эту ветку **не включены**.
Подсказки пока показывают кнопки геймпада. Меню управляются клавиатурой или геймпадом,
выбор элементов курсором не реализован. Часть фоновых элементов остаётся 16:9.

## Запуск

Когда архив опубликован, скачайте его из [Releases этого форка](https://github.com/DuckInTheDuck/bloodborne_pc/releases).

1. Распакуйте весь переносимый пакет.
2. Поместите файлы игры в `game/` или выберите существующую папку в лаунчере.
   Непосредственно в ней должны лежать `eboot.bin`, `dvdroot_ps4/`, `sce_module/` и `sce_sys/`.
3. Запустите `Bloodborne.exe`, выберите разрешение, сглаживание и ограничение FPS, нажмите **Играть**.

Готовая сборка не требует Python, MSYS2 или компилятора.
Нужны Windows 10/11 x64 и актуальный драйвер с Vulkan 1.3.
FSR 4 дополнительно требует совместимых возможностей Vulkan и шейдерных ассетов.
Разрешение определяется при первой настройке; дальнейший выбор сохраняется.

По умолчанию WASD перемещает персонажа, мышь вращает камеру, стрелки управляют меню.
Space подтверждает, Left Shift возвращает назад. Действия переназначаются в разделе
«Управление» лаунчера или оверлее настроек (**Insert**).
Оригинальное игровое меню не ставит игру на паузу.

В переносимой сборке настройки и сохранения находятся в `user/`, подготовленные данные — в `out/`.
При проблемах приложите `user/last_run.log` и сведения о процессоре, видеокарте и драйвере
к [issue этого форка](https://github.com/DuckInTheDuck/bloodborne_pc/issues).
Перед удалением программы сохраните резервную копию `user/`.

## Сборка

```bash
git clone --recursive https://github.com/DuckInTheDuck/bloodborne_pc.git
cd bloodborne_pc
```

Далее используйте [инструкцию для Windows](packaging/windows/README.md):
`bash build.sh` собирает проект, `bash packaging/windows/package.sh` создаёт пакет.
FSR-Vulkan использует закреплённый подмодуль и патчи из `gpu/patches/fsr-vulkan/`.
Упаковщик рекурсивно проверяет зависимости DLL.
Исходники Linux сохранены, но последние проверки этого форка проводились на Windows.
Исходная документация: [English](docs/upstream-README.md), [Русский](docs/upstream-README.ru.md).

## Статус и авторы

Экспериментальный проект. Сборка проверена автором на нескольких ПК;
полное прохождение и все сочетания оборудования не проверены.
Совместимость и производительность зависят от драйвера, сцены и настроек.

- Оригинальный рантайм и порт Linux — **deadinside28**.
- Порт Windows и исходный лаунчер — **Supermedo**.
- Доработки управления ПК, ультравайда, лаунчера и упаковки — **DuckInTheDuck**, при помощи **OpenAI Codex (GPT-6)**.
- Рендерер и компилятор шейдеров — участники **shadPS4**.
- Апскейлинг — **AMD FidelityFX / FireBurn FSR-Vulkan**.
- Авторы патчей указаны в `patches/Bloodborne.xml`.
