# Game files / Файлы игры

Place your own decrypted **Bloodborne CUSA03173, version 1.09** files here,
or select an existing game folder in the launcher. No game files are included.

Поместите сюда свой расшифрованный дамп **Bloodborne CUSA03173, версия 1.09**,
или выберите существующую папку игры в лаунчере. Файлы игры не включены.

```text
game/
  eboot.bin
  dvdroot_ps4/
  sce_module/
  sce_sys/
```

Do not add an extra CUSA03173 folder inside this folder.
Не создавайте дополнительную вложенную папку CUSA03173.

For a ready-to-run program, download the ZIP from this fork's Releases.
Для запуска без сборки скачайте ZIP из Releases этого форка.
